# Desk Runbook — how a scheduled session runs one mode

Vault repo (source of truth): https://github.com/mtmadi2002-commits/trading-desk-vault
Vault artifact (live mirror + database state/journal/alerts): https://claude.ai/artifact/JSScJUS6LxVYYfr98XfUVL
Playbook page (human view of the latest plan): https://claude.ai/artifact/3p1oPXKJcVnqULQmMMEgFr

The routines fire INTO the desk's own Claude Code session (it holds the Alpha Vantage and Firecrawl connectors); the container may have been recycled, so always re-fetch the vault from the artifact. Follow these steps exactly; each mode section says what to read, run and write.

## 0. Bootstrap (all modes)
1. `TZ=America/New_York date "+%Y-%m-%d %H:%M %A"` → NOW_ET, TODAY, DAY. Session date = TODAY for premarket/monitor/coach; for plan mode it is the NEXT US trading day (skip Sat/Sun; if TODAY is Friday the plan is for Monday).
2. THE VAULT IS A GIT REPO: https://github.com/mtmadi2002-commits/trading-desk-vault, attached to this session at `V=/home/user/trading-desk-vault`. If `$V/.git` exists run `git -C $V pull --rebase origin main`, else `git clone --depth 50 https://github.com/mtmadi2002-commits/trading-desk-vault $V` (timeout 10 min; on HTTP 429 sleep 10 s and retry once). Always use this exact path: the permission rules that let scheduled runs execute and push are scoped to it. If git is refused, fall back to Artifact `read` of the vault artifact with `paths` for the files you need and `out_dir` $V, and say so in the note.
3. Load ArtifactData via ToolSearch `select:ArtifactData`. `get` collection `state` doc_id `desk` → remember its `version`.
4. BEFORE launching: `update` state/desk (pin `if_version`) with `now_running: {mode, seats: [<seat keys this mode runs: plan → screener,macro,technical,catalyst,smart-money,head-trader,risk; premarket → head-trader,execution; monitor → execution,smart-money; coach → coach>], since: <ISO now>, doing: {}}` so the Desk Floor page shows the bots working. Use a workflow: `Workflow({ scriptPath: "$V/Scripts/desk.workflow.js", args: {...} })`. args always include: mode, date (session date), day, now_et, vault_dir ($V), vault_url, rules (the full text of Desk/Rules.md), av_calls_remaining (25 − state.desk.av_calls_used_today; resets at midnight ET).
5. After the workflow returns, write results into $V as the mode section says, then run as SEPARATE commands: `git -C $V add -A`; `git -C $V -c user.name="Trading Desk" -c user.email="desk@users.noreply.github.com" commit -m "<mode> <date> <HH:MM ET>"`; `git -C $V push origin main` (on rejection: `git -C $V pull --rebase origin main` once, push again). Then MIRROR to the artifact: Artifact `publish` with `url`=<vault artifact>, `file_path`=$V/index.html, `files` mapping ONLY the notes you changed or created (read a file via `paths` first if you did not create it this session). Then write the ACTIVITY rows (collection `activity`, one `set` per seat that ran, doc_id `<date>-<HHMM>-<seat>`: {ts (ISO with -04:00/-05:00 offset), date, time_et, seat (key: screener|macro|technical|catalyst|head-trader|risk|smart-money|execution|coach), seat_name, mode, status: done|refused, summary (one sentence of what it concluded, with the numbers), tool_uses (from the workflow result's per-agent counts if available, else the total), duration_s, run_id}) — a `batch` of up to 50 writes is one call. Finally `update` state/desk (pin `if_version`) with `now_running: null`, av_calls_used_today += the calls the seats reported, and `last_run: {mode, at, commit}`. Also `set` `equity` and `day_pnl_pct` from `exec.py positions` when the mode ran it. Note: `$V/index.html` is the Desk Floor page; publish it unchanged as `file_path` (its file list is static — regenerate with `python3 -I $V/Scripts/inject_files.py` only when notes were added).
6. Never trade live: this is a PAPER desk. Never invent a price. If a data source is down, say so in the note and in the alert, and stop. Obsidian on the user's machine pulls `main` every 5 minutes (Obsidian Git plugin), so a push IS the sync.

## plan (evening, ~20:55 ET Sun–Thu; session date = next trading day)
Read additionally: the most recent `Reviews/*.md` and `Lessons/*.md` if any, and yesterday's plan for context. BUILD THE LESSONS FILE: `python3 -I $V/Scripts/build_lessons.py` writes `$V/Desk/Lessons Digest.md` (latest 3 reviews' grades + what worked/failed + every Lesson note, newest first, capped at ~12k chars) — pass `lessons_path: $V/Desk/Lessons Digest.md` in the workflow args so every seat reads it. The same script writes `$V/Desk/Expectancy.md` (per-setup stats from `exec.py stats`) — pass `expectancy_path: $V/Desk/Expectancy.md` too (plan AND coach). BACKTEST (plan mode, optional): if `python3 -I $V/Scripts/broker/exec.py quote --symbol SPY` returns ok (Alpaca paper keys exist), then for each top-3 plan ticker run `exec.py bars --symbol T --days 60` and `python3 -I $V/Scripts/backtest.py T --md $V/Backtests/`; hand the result summaries to the Head Trader as `backtests` in prior_notes and link `[[T Backtest]]` from the plan note. Without keys, skip (Alpha Vantage's free key cannot serve 5-minute history). The Coach also reads it in coach mode (pass the same arg) so lessons accumulate instead of repeating.
args.prior_notes: 3–8 lines you verify yourself first with Firecrawl (7 s apart): SPY close/prev close/day range from https://stockanalysis.com/etf/spy/ ; the top 3 finviz screener themes (https://finviz.com/screener.ashx?v=111&s=ta_topgainers&f=sh_avgvol_o1000,sh_price_o5 and ta_mostactive); any headline that dominated the day.
Write: `Plans/<date> Plan.md` via `python3 -I Scripts/render_plan.py run.json <date> out.md` (save the workflow result JSON first; add `rules_version` and `run_id` keys to the JSON before rendering); `Journal/<date> Journal.md` from Templates/Journal.md; update Dashboard.md "Latest" links and add a scorecard row with planned trade count. PLAYBOOK PAGE: `python3 -I $V/Scripts/render_playbook.py run.json <date> $V/Plans/<date>.playbook.html <run_id>` then Artifact `publish` with `url`=https://claude.ai/artifact/3p1oPXKJcVnqULQmMMEgFr and `file_path`=that html (read the artifact first if this session has not published it). Database: `set` state/desk fields session_date, plan (the `final` object), rules_version, premarket_status "pending", plus `delete` any `journal`/`alerts` docs from a previous date (list first). Push summary: regime, the ranked trades with entry/stop/T1/size, the vetoes, the two numbers to watch at the open.

## premarket (08:50 ET weekdays; session date = today)
Read additionally: `Plans/<today> Plan.md`, `Journal/<today> Journal.md`. args.lessons_path = `$V/Desk/Lessons Digest.md` (run build_lessons.py first); args.plan_path = `$V/Plans/<today>.desk.json` (the plan JSON the evening run saves next to the note; state/desk.plan holds the same `final` object), args.rules_path = `$V/Desk/Rules.md`.
Write: append a "## Premarket update (HH:MM ET)" section to the Plan note with the trade_status table, checklist answers, kill switches tripped and the alert text; `update` state/desk premarket (the whole object) and premarket_status (e.g. "2 live, 1 scrapped"). Push: the alert_text.

## monitor (hourly at :40, 09:40–15:40 ET weekdays — the platform minimum is 1 h; session date = today)
If NOW_ET < 09:30 or > 16:05, stop (say why). Read additionally: the Plan and Journal notes, `Desk/Live.md`, and `Journal/ledger.json` if present. args.plan = state.plan, args.premarket = state.premarket, args.journal = `list` collection `journal` ordered by ts (today's rows only) PLUS the ledger positions.
EXECUTION (this is where paper orders happen): the workflow's execution seat only DECIDES (paper_actions); you EXECUTE each one, in order, through the broker layer, which enforces the guards and refuses anything outside them. Always the exact command form below (`E=python3 -I /home/user/trading-desk-vault/Scripts/broker/exec.py --unattended`):
- FIRST, every tick: `$E quote --symbol SPY`. If ok → REAL-TIME QUOTES ARE AVAILABLE: pass that sentence in args.journal context, quote every plan ticker with `$E quote` and give the seat those prices (indicative=false). If refused (no keys) → finviz delayed quotes as before.
- RESTING ORDERS (alpaca-paper / alpaca-live only; refused in paper-local): at the 09:40 tick, for every plan trade the premarket update marked live/halved, `$E rest --symbol T --side buy|sell --trigger <entry trigger level> --limit-cap C --stop S --t1 T1 --risk-pct R --setup <setup_type>`; the broker fires the entry when the trigger prints. Later ticks: `$E orders` to see what rested/filled, `$E cancel --symbol T` for anything a kill switch or the premarket update scrapped, and manage fills with scale/breakeven/exit below. Never rest a trade the premarket run scrapped.
- enter → `$E enter --symbol T --side buy|sell --entry E --stop S --t1 T1 [--t2 T2] --risk-pct R --limit-cap C --fill LAST --setup <setup_type from the plan trade>` (LAST = the last price the seat saw; in paper-local the fill is LAST and is refused if worse than the cap)
- TRAIL, every tick, for EVERY open position BEFORE deciding exits: `$E trail --symbol T --last LAST` (applies the rising-stop ladder in Desk/Trail.md; the stop only rises). If the result has `stop_hit: true` → `$E exit --symbol T --reason "ladder stop <stop>" --fill <stop>` and push it. Give the seat the new stop in the journal context.
- scale → `$E scale --symbol T --fraction 0.3333 --fill LAST` (one third at T1 per Rules v4 'Winners'), then `$E stop-to-breakeven --symbol T`; the two-thirds runner trails and is exited only by `exit` on the trail / stall / kill switch / 15:55 flat
- stop / target / exit-rule → `$E exit --symbol T --reason "<rule>" --fill LAST`
- at the 15:40 tick, after the seat's actions: `$E flatten --reason "15:55 flat rule"` if `$E positions` shows anything open.
Record the exec.py JSON result (ok / refused + reason) in the journal row's `evidence`, and ALSO copy these fields from the exec.py result onto the journal row so the 3D floor can animate the order: qty, stop, t1, t2, clipped (true/false), eff_risk (risk_pct_effective), equity (from positions before the order), floor. A refusal is NOT an error to work around — it is the risk layer doing its job; log it and move on. Never call exec.py with numbers the seat did not output. Mode is whatever `Desk/Live.md` says (paper-local today); scheduled runs can never place a real-money order unless the user has set `allow_unattended_live: true` there.
Write: for each paper_action with action ≠ 'none', `set` journal doc_id `<HHMM>-<TICKER>-<action>` {ts (ISO), time_et, date, ticker, direction, action, price, size_pct, rule, evidence, indicative: (true in paper-local, false in alpaca-* modes)}; for each alert `set` alerts doc_id `<HHMM>-<n>` {ts, time_et, date, severity, text, source}; append one line per action/alert to the Journal note's tables; `update` state/desk open_positions (from `$E positions`), day_pnl_pct_indicative, kill_switches_tripped. ALSO `set` state doc `quotes` = {ts, as_of_et, delay_note, quotes: [the seat's quotes array: ticker, last, change_pct, day_high, day_low, volume, source], next_update_et} — the Desk Floor's Live tape reads it; and keep `open_positions` entries complete (ticker, direction, qty, entry, stop, t1, size_pct) so the tape can mark them to market. Commit `Journal/ledger.json` with the notes. PUSH (PushNotification, one line, < 200 chars) for EVERY fill, scale, stop, target, exit, rest, and refusal — e.g. `FILL NU long 13.15 @15.22 stop 14.72 T1 16.00 (5% risk, eq $200)` / `STOP SPCX -$5.90 (-2.9%) eq $194.10` / `REFUSED NVDA: max concurrent 2`; plus one for a critical alert. A tick with no action ends quietly with one line and no push.

## quote-refresh (hourly at :10, 10:10–15:10 ET weekdays — the light tick between monitors; NO workflow, NO orders)
Purpose: keep the Desk Floor's Live tape and the open positions' unrealized P&L fresh between the :40 monitor ticks. Steps: `git -C $V pull --rebase origin main`; `$E positions` (open positions) and `jq .final.trades[].ticker $V/Plans/<today>.desk.json`; try `$E quote --symbol T` for each plan ticker + SPY (works once Alpaca keys exist; indicative=false); if refused, Firecrawl-scrape https://stockanalysis.com/stocks/<t>/ (ETFs: /etf/<t>/) one at a time with `sleep 7` and read last / change / Day's Range. Then `set` state doc `quotes` as in the monitor section, and `update` state/desk (pin if_version) with `open_positions` (unchanged list, plus `last` per position) and `last_run: {mode: "quote-refresh", at}`. For every open position run `$E trail --symbol T --last LAST` so the rising-stop ladder keeps pace; if `stop_hit` → `$E exit` + push (that is the only order this tick may place). Do NOT run the workflow, do NOT enter anything, do NOT push otherwise; end with one line. Budget: ≤ 6 scrapes, 0 Alpha Vantage calls.

## coach (16:24 ET weekdays; session date = today)
Read additionally: Plan, Journal, Dashboard, `Rules Changelog`, all `Lessons/*.md` titles (file list). args.plan, args.premarket, args.journal as above, plus `Journal/ledger.json` (the executed record: fills, scales, exits, realized P&L) — the replay is compared against the LEDGER, not only the journal rows. Run `python3 -I $V/Scripts/build_lessons.py` first and pass `expectancy_path: $V/Desk/Expectancy.md`. BARS FOR THE REPLAY: if `$E quote --symbol SPY` is ok, `$E bars --symbol T --days 3` for each plan ticker + SPY gives exact 5-minute bars in `Data/bars/T-alpaca.json` (use these; Alpha Vantage intraday returned 'premium endpoint' on the free key on 2026-10-06 — if AV fails, this or stockanalysis is the fallback). Also pass `targets_path: $V/Desk/Targets.md` (user milestones; the Coach reports pace against them and never loosens a limit for them).
Write: `Reviews/<today> Review.md` = coach.review_md; one `Lessons/Lesson - <title>.md` per lesson (Templates/Lesson.md shape, status "proposed" or "applied in Rules v<N>"); if any rule change applied: overwrite `Desk/Rules.md` with coach.new_rules_md (frontmatter version +1, updated date, updated_by Coach) and append rows to `Desk/Rules Changelog.md`; replace the day's indicative journal docs with exact ones from coach.replay (`set` doc_id `<HHMM>-<TICKER>-<action>` with indicative:false; delete the indicative docs you replaced); update Dashboard.md scorecard row (triggered, wins, losses, day R, day P&L %, rules v) and Latest links; `update` state/desk scorecard (array), rules_version, day_pnl_pct. Also update the ticker notes: create/append `Tickers/<TICKER>.md` with one line per trade (date, plan link, result R). After writing, run `python3 -I $V/Scripts/build_lessons.py` again so `Desk/Expectancy.md` includes today's closed trades and commit it. Push: day R and P&L, seat grades in one line each, lessons titles, rule changes applied, pace vs targets sentence.

## Execution modes
The paper account starts at $200 and compounds: `exec.py positions` returns equity, equity_start and profit — write all three to state/desk after any order so the Floor shows them. Fractional shares are allowed in paper modes only.
`Desk/Live.md` sets the mode (paper-local now → alpaca-paper → alpaca-live). `exec.py --unattended preflight` shows the resolved state. Only the user edits Live.md. In alpaca-* modes the keys come from environment secrets ALPACA_KEY_ID / ALPACA_SECRET_KEY and the hosts must be on the environment network allow-list; if preflight fails, the day runs read-only and the premarket alert says so.

## Budgets (per day, desk-wide)
Alpha Vantage free key: 25 calls/day. plan ≤ 11, coach ≤ 5, premarket 0, monitor 0. Firecrawl ≈ 10 req/min: one request at a time, `sleep 7` between.
